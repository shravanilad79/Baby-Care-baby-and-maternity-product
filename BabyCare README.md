# 🍼 BabyCare – Baby & Maternity Products

BabyCare is a responsive **baby and maternity e-commerce website** created using HTML, CSS, and JavaScript.

The website provides a simple shopping experience where users can browse baby products, filter products by category and age, search and sort products, add items to a cart, manage a wishlist, view product details, create a gift registry, and subscribe for baby essentials.

---

## 📌 Project Overview

**Project Name:** BabyCare
**Project Type:** E-Commerce Website
**Domain:** Baby & Maternity Products
**Technology:** HTML, CSS, JavaScript
**Project Structure:** Single HTML file

The website is designed to provide products for different stages of a baby's growth along with maternity essentials.

---

## ✨ Features

### 🏠 Home Section

* BabyCare branding and navigation bar
* Hero section with introduction
* "Shop Products" button
* Responsive layout
* Promotional shipping message

### 🛍️ Product Categories

Users can browse products through different categories:

* Baby Care
* Baby Clothing
* Toys & Play
* Maternity
* Feeding

Selecting a category filters the available products.

### 👶 Age-Based Filtering

Products can be filtered according to baby age:

* All
* 0–6 Months
* 6–12 Months
* 1–2 Years
* 2+ Years

This makes it easier to find products suitable for a particular age group.

### 🔎 Search and Sorting

The product section includes:

* Product search
* Price: Low to High
* Price: High to Low
* Name A-Z
* "No products found" message when there are no matching products

### 🛒 Shopping Cart

Users can:

* Add products to cart
* Increase or decrease quantity
* Remove products
* View total price
* Open and close the cart
* Proceed to checkout

The cart is managed using JavaScript.

### ❤️ Wishlist

Users can add or remove products from their wishlist using the heart button.

The wishlist is maintained using JavaScript during the current session.

### 👀 Quick View

The **View** button opens a quick product preview containing:

* Product image
* Product name
* Age/category information
* Price
* Add to Cart option

---

## 🎁 Gift Registry

BabyCare includes a **Baby Gift Registry** section.

Users can enter:

* Name
* Email address
* Event name
* Registry message

The registry can be used for birthdays, baby showers, and other special occasions.

---

## 📦 Subscription

The website also includes a subscription section for everyday baby essentials.

Users can enter their email address and subscribe to receive essential products automatically.

---

## 📱 Responsive Design

The website is designed to work on different screen sizes.

Responsive CSS is included for:

* Desktop
* Tablet
* Mobile

On smaller screens, the product grid, categories, search area, subscription form, footer, and quick-view section automatically adjust to fit the screen.

## 🚀 How to Run the Project

### Method 1 – Directly in Browser

1. Download or clone the project.
2. Open the project folder.
3. Double-click `BabyCare.html`.
4. The website will open in your browser.

### Method 2 – Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `BabyCare.html`.
3. Install the **Live Server** extension if required.
4. Right-click the HTML file.
5. Select **Open with Live Server**.
